# Annotation neuron

Thư mục này chứa bảng annotation được kiểm chứng cho neuron và pathway. Mỗi
dòng phải có `neuron_id` đúng với connectome đang chạy và một `source` có thể
truy nguyên. Không được suy ra neuron dopamine hoặc motor neuron từ vị trí
trong tensor.

File `neuron_annotations.template.csv` chỉ là template, chưa chứa dữ liệu
khoa học. Dữ liệu thật cần được nhóm nghiên cứu điền và review thủ công.
