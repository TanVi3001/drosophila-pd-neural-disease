# Generation 2 Claim Policy

## Current allowed statement

> This project is developing a connectome-constrained embodied computational
> framework for evaluating paper-guided Parkinson-like locomotor hypotheses in
> *Drosophila*.

## Allowed terms when supported by the corresponding evidence

- computational model;
- Parkinson-like locomotion model;
- paper-guided replication;
- computational concordance;
- candidate mechanism model;
- external computational validation, only when study-level holdout conditions
  are actually satisfied.

## Forbidden current claims

- complete Parkinson model;
- biologically validated Parkinson model;
- digital twin;
- gene-specific biological validation;
- causal mechanism proven;
- wet-lab replacement;
- drug efficacy;
- clinical prediction.

Generation 2 is a program under construction. Future target language such as
“the model generalizes” must not be presented as an achieved result.
