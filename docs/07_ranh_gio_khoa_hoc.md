# Ranh giới khoa học

Repository này xây dựng mô hình perturbation neural-body tính toán có định
hướng bởi literature. Nó không phải:

- mô hình Parkinson sinh học hoàn chỉnh;
- mô phỏng dopamine thật;
- mô phỏng alpha-synuclein aggregation;
- mô phỏng ty thể ở cấp phân tử;
- mô phỏng chết tế bào thật;
- mô hình chẩn đoán;
- mô hình dự đoán lâm sàng;
- mô hình đáp ứng thuốc.

Khi có calibration và holdout tốt, kết luận chỉ nên nói rằng mô hình tái tạo
một số locomotion phenotype được báo cáo trong literature ở mức tính toán.
Mọi giả thuyết về cơ chế phải được kiểm chứng độc lập bằng dữ liệu sinh học.
