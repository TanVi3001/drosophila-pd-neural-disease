# Gate 21C - Healthy comparability audit

**Trạng thái:** `HEALTHY_COMPARABILITY_ACCEPTABLE_FOR_RATIO_ANALYSIS`

| Hạng mục | Giá trị |
| --- | --- |
| Real DTHg; ple median speed | 10.8 mm/s |
| Virtual healthy median speed | 2.5853208610209686 mm/s |
| Chênh lệch tuyệt đối | 8.214679138979033 mm/s |
| Unit | `MATCH` |
| Statistic/unit of analysis | `LIMITED_DIFFERENT_UNIT_OF_ANALYSIS` |
| Assay | `RATIO_ANALYSIS_WITH_LIMITATIONS` |
| Absolute scale | `ABSOLUTE_SCALE_MISMATCH` |

Scale thô không được ép khớp bằng calibration. Gate sau chỉ được dùng normalized disease/control ratio theo contract, với giới hạn assay được giữ nguyên.
