# Cấu hình condition

Các file YAML trong thư mục này là cấu hình nghiên cứu, không phải kết quả
đã được hiệu chuẩn. `burden_curve` phải được điền bằng các mốc có provenance;
nếu để trống, CLI trả `WAITING_TARGET_DATA` và không tạo edge weight mới.

Các tham số trong `full_burden` là tham số cần hiệu chuẩn, không phải số liệu
sinh học mặc định. Giá trị trung tính trong template chỉ dùng để mô tả schema.
